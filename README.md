# DentalOS SaaS

Multi-tenant Dental Clinic SaaS platform.

## Status

Repository initialized for the DentalOS development roadmap.

## Planned Architecture

- Monorepo: Turborepo
- Frontend: Next.js + React + TypeScript
- Database: PostgreSQL (Supabase)
- ORM: Prisma
- Authentication: Better Auth
- Storage: Supabase Storage
- Background jobs: Inngest
- Email: Resend
- Payments: Razorpay
- Error monitoring: Sentry

## Applications

- Marketing website
- Super Admin portal
- Clinic portal
- Patient portal
- API/service layer

## Development Principle

Build the platform in vertical slices with tenant isolation, RBAC, auditability, and security designed into the foundation.
